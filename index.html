Hubungkan ke Google Sheet (Apps Script API)

Tempel URL Web App dari Google Apps Script agar setiap transaksi tambah, edit, hapus, dan update modal langsung tersimpan ke Google Sheet secara real-time.

Tautan Proyek Anda:
Buka Google Sheet Buka Repo GitHub URL GitHub Pages

Langkah Deploy ke GitHub Pages

  1. Buka Google Sheet Anda → klik Extensions (Ekstensi) → Apps Script.
  2. Salin kode Apps Script di bawah, tempel di editor, lalu klik Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone).
  3. Salin URL Web App (.../exec) lalu tempel di kolom sebelah kiri (atau isi langsung di variabel DEFAULT_API_URL dalam index.html).
  4. Upload index.html ke repositori newsistim/Laporan-Uang-Keluar (branch main).
  5. Di GitHub buka Settings → Pages → pilih branch main / / (root) → klik Save.
