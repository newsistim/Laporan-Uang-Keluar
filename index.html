Cara pasang di Sheet & GitHub Pages

Rumus kolom H sudah memakai pemisah titik koma (;)

  1. Buka Google Sheet Anda, klik Extensions → Apps Script.
  2. Tempel kode Apps-Script-Code.gs di bawah, lalu simpan.
  3. Klik Deploy → Manage deployments → Edit → New version (Execute as: Me, Who has access: Anyone), lalu klik Deploy.
  4. Unggah index.html ini ke branch main di repositori newsistim/Laporan-Uang-Keluar.
  5. Buka Settings → Pages di GitHub, pilih branch main / root, lalu simpan.
